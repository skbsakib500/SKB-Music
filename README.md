# SKB Music

> A privacy-first Android music player.
> Local files. No internet. No tracking. No ads.

[![Build](https://github.com/skbsakib500/SKB-Music/actions/workflows/build.yml/badge.svg)](https://github.com/skbsakib500/SKB-Music/actions)

## Features

- 🎵 Media3 ExoPlayer
- 💾 Room DB (library, playlists, favorites, recents)
- 🎨 Dynamic gradient from album art
- 📊 Real-time spectrum visualizer
- 🎚️ 10-band EQ + bass boost + virtualizer
- 🔊 ReplayGain
- 💬 Lyrics (.lrc + embedded)
- 😴 Sleep timer, ⏩ playback speed
- 🔔 Custom notification + MediaSession
- 📈 Listening stats

## Install

Download APK from [Actions](https://github.com/skbsakib500/SKB-Music/actions) or:

    git clone https://github.com/skbsakib500/SKB-Music.git
    cd SKB-Music && ./gradlew :app:assembleDebug

## Tech Stack

Kotlin · Compose · Material3 · Media3 1.4.1 · Room 2.6.1 · DataStore · Coil 2.7.0 · Palette · Navigation Compose · SDK 24-34
